# Mellow PDF Reader 1.0.0

**A softer way to read.** An offline Windows 10/11 x64 PDF reader with compact tabs,
comfortable page themes, independent split reading and focused PDF tools.

## Downloads

- **MellowPDFReader-1.0.0-Setup-x64.exe** — Windows installer.
- **MellowPDFReader-1.0.0-Portable-x64.zip** — extract the whole folder and run MellowPDFReader.exe.
- **MellowPDFReader-1.0.0-Source.zip** — source and packaging materials matching these Windows downloads.

The separate `qtbase`, `qtsvg`, `qtimageformats`, `qtwebengine` and `pyside-setup`
archives are corresponding library sources. They are optional downloads for
studying or rebuilding the libraries; normal installation does not require them.

## Features

Light, Sepia, Dark and Black page themes; continuous and facing-page layouts;
search and text copying; bookmarks, Favorites and session restoration; independent
split panes; Quick Jump and Back/Forward navigation; sharp page previews;
reference previews, magnifier, ruler and auto-scroll; PDF split, merge and images
to PDF; customizable shortcuts and local app backup/restore.

Release cleanup fixes numeric/scroll boundaries, updates PDF tooling, uses a
patched Python runtime and removes unused bundled dependencies. Version-specific
Qt/PDFium notices and native-library attribution accompany both Windows packages.
Original PDFs are not imported into an internal library or changed by reading.

## Verification and limits

Windows regressions: **{{PASSED_TESTS}} passed**. Native caption/reading-aid checks,
frozen and installed PDF rendering, portable rendering, PDF Open with registration,
update preservation and uninstall cleanup passed. The release required Defender
**NoThreatsReported** for the application and installer. This is a point-in-time
scan, not a safety guarantee.

**Unsigned:** no trusted publisher certificate is configured. Windows may show a
SmartScreen reputation warning. Do not disable antivirus or add exclusions.
Scanned PDFs need an existing text layer for search/selection; OCR is not included.
Complex reference matching and figure-color preservation have documented fallbacks.
Physical touchpad, mixed-DPI and accessibility testing remains a device checklist.
