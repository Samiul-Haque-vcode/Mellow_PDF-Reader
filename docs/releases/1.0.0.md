# Mellow PDF Reader 1.0.0

**A softer way to read.**

An offline Windows PDF reader with compact tabs, comfortable reading themes and independently navigable split panes.

## Included

- Light, Sepia, Dark and Black reading themes with page recoloring and figure-color controls.
- Continuous, single-page and facing-page layouts; sharp three-column Small and two-column Large page previews.
- Search, text selection/copying, temporary Quick Jump markers and Back/Forward history.
- Favorites, bookmarks, recent documents, session restoration and metadata backup/restore.
- Magnifier, reading ruler, auto-scroll, zoom lock and source-PDF reference previews.
- Extract pages, merge PDFs and convert images to PDF, with previews and cancellation.
- Customizable shortcuts and compact settings.

## Cleanup and fixes

- Clamp line/screen/selection scrolling before passing positions to Qt, including extreme document ranges.
- Validate unusually large metadata numbers without conversion overflow; invalid backup data leaves existing saved locations unchanged.
- Update the PDF utility dependency to pypdf 6.21.4 or newer.
- Reorganize the README around setup, features, settings, data, tools and development.
- Replace historical review notes with concise public security guidance. No personal PDFs, local metadata, secrets, demo media or compiled caches are included in this source tree.

## Distribution status

This is a **source release**. GitHub provides the source ZIP and tar archive below. No Windows executable, installer or portable binary is attached: the complete version-specific Qt/PDFium attribution bundle remains outstanding. Follow the README to run from source or build locally, and complete the distribution requirements before redistributing binaries.

No trusted publisher certificate is configured. Source checks and tests do not establish SmartScreen reputation, malware-scan results or physical Windows-device compatibility. See VALIDATION.md and THIRD_PARTY.md for scope and limitations.
