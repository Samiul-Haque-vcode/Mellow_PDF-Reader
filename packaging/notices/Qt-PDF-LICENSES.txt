Qt libraries are loaded dynamically and kept separate from the executable.

The qt-pdf-6.140.0 folder contains nine upstream license-text snapshots for
PDFium, Chromium, Abseil, FreeType, fast_float, ICU, libjpeg-turbo, libpng and
zlib. qt-pdf-manifest.json records the source URL, documentation version,
retrieval date, original HTML SHA-256 and extracted text SHA-256 for each.
Text was extracted from the upstream license code blocks, decoding HTML
entities. These are attribution materials, not an assertion that the exact
wheel's corresponding sources or every other native library were reviewed.
